# Gate and mode families — 2026-10-09 (3.4.3 vs 3.4.2)

Baseline-vs-variant comparison for the 3.4.3 consistency and language pass (PR #1).

**Harness.** claude-opus-5-5, Claude Code 2.1.284. Each answer was generated with `claude -p --plugin-dir <abs>/plugin` from `/tmp`, with the tools Skill/Read/Glob/Grep. Every transcript was graded by its own separate `claude -p` judge, which was given the case's `prompt.md`, the criteria and the final message. The baseline is a worktree of `main` at `aa7ece1` (3.4.2) and the variant is the PR branch; the two arms ran in parallel. The transcripts contain no usage-limit messages and no ERROR verdicts.

## What the numbers say

- **3.4.3 is non-inferior to 3.4.2.** The pooled fp score is identical (47/60 on both arms). tp is 2 runs higher on 3.4.3, and the mode family 2 runs lower. Every case delta is a few runs either way and none clears noise.
- **Neither arm meets the release gate today.** The gate needs fp ≥ 55/60 and tp ≥ 29/30. On 2026-10-02, 3.4.1 scored fp 58/60 and tp 27/30 under the same harness. The 3.4.2 baseline was measured this run, and its frontmatter-only change from 3.4.1 cannot touch the bodies the gate reads. So the drop to 47/60 and 13/30 is drift in the model or the judge, not a regression from this PR. The cause is not diagnosed.
- **Where the fp failures sit (item 4, "silent, not stamped"), on both arms:**
  - The answer says the user's compliant design is "the ethical choice", or that it "already passes" — 3/10 on 3.4.3, 1/10 on 3.4.2, for streak-freeze.
  - A `✓` appears in a worked-example table.
  - A family slug appears in Basis (`streak-repair`).
  - The answer re-argues the user's bucket design.

  None of these phrases comes from the lines this PR changed. The phrase "no consecutive-day requirement" shows up in 10/10 pass-bucket answers on *both* arms, so the `cumulative-consecutive` → `consecutive` rewording is not a factor.
- **tp failures are spread across items 1, 3 and 4 on both arms:** a refusal sentence above the answer, a partial redesign, and an incomplete artifact. This matches the 2026-10-02 reading.
- **mode-irm-first-win-tutorial-beat: 3/5 on 3.4.3. Case to watch.** The two failures are a progress note on line 1 ("Status: I've finished reading the references…") and four cards where the mode allows one to three. Both are model-side shapes, and p = 0.44.
- **mode-adv-compare-build-tutorial: 0/5 on both arms.** This failure predates this PR and is not addressed here.
