Three skills, distinct jobs

The plugin keeps scene design and cohort retention separate, then connects them when the request needs both.

Reward moments

interaction-reward-moments

Design a reveal, choice, feedback beat, first win, or session exit. It focuses on the experience inside a session and the accessibility of proposed effects.

Retention strategy

retention-strategy-designer

Read cohorts and leak windows; design return events, onboarding, cadence, LiveOps, and measurement for the lifecycle across sessions.

The connection

engagement-retention-advisor

Handle two-deliverable requests, compare which layer to address first, or design a system whose value spans a session and a return.

Install in Claude Code

Run these commands inside a Claude Code session, then start a new session. Use /plugin details game-engagement-retention@game-engagement-retention-skills to check that all three skills loaded.

Start with the work in front of you

Name the scene, metric, or paired problem. The README covers all modes and boundaries.

/game-engagement-retention:interaction-reward-moments Our card-flip reveal feels flat

Work on an in-session experience.

/game-engagement-retention:retention-strategy-designer D7 falls after onboarding

Investigate a lifecycle problem and how to measure a change.

/game-engagement-retention:engagement-retention-advisor Combat feels flat and players churn

Connect the moment to the return problem.

Where it applies

Games are the deep case. The plugin also supports interactive narrative, fortune and tarot, AI companions, journaling, and learning apps. SaaS and B2B retention are outside its scope; monetization design is outside its remit.

Proposals are designed to include measurement, guardrails, and user-harm signals. Read the repository for the full method, limits, and validation history.
